## 看不懂怎么办

每课结果都带两块辅助：

**白话解**——紧跟在结果下方，用三到四句话说明白：这一课是什么意思、为什么这么断、接下来该怎么做。不需要任何基础就能读懂。

**术语释义**——结果页底部列出本课用到的术语，点任意一个即弹出白话解释（一句人话 + 稍展开）。也可点「全部术语」查看完整词典，共 74 条，分通用、六壬、梅花、六爻、奇门五类。

六十四卦另有逐卦白话译文与「怎么用」提示，见 `js/meihua-bai.js`。

## 罗盘（奇门专用）

奇门起局后，结果页有「开罗盘·找方位」按钮，直接调手机方位传感器：

- 表盘随手机转动，红色指针指向你正前方
- 八宫方位（坎北、艮东北…）连同当值八门一起标出，三吉门用金色圆圈突出
- 顶部实时提示「向左转 118°」「已对准，朝这个方向走」
- 无需传感器时可点右上「切换」进入手动模式，拖动表盘对齐北方

**已知限制**：手机罗盘用磁力计测向，受金属、车辆、磁性手机壳干扰时误差可达 ±15°。判断大致方位够用，若要精确到山向请用专业罗盘。另外 iOS 需用户点击授权；非 https 环境（如局域网 IP）无法读取传感器。

## 六爻纳甲规则

摇卦用三枚铜钱：三背为老阳（重，动）、两背一字为少阴（拆，静）、一背二字为少阳（单，静）、三字为老阴（交，动）。

- **八宫**：以八纯卦为首，逐爻变而上——本宫、一世至五世、游魂（复变四爻）、归魂（下卦复归）。世应随之而定：本宫世六应三，一世世初应四，依次类推，游魂世四应初，归魂世三应上。
- **纳甲**：乾纳甲壬、坤纳乙癸、震纳庚、巽纳辛、坎纳戊、离纳己、艮纳丙、兑纳丁。阳卦（乾震坎艮）顺行阳支，阴卦（坤巽离兑）逆行阴支。
- **六亲**：以本宫五行为我——同我者兄弟、生我者父母、我生者子孙、克我者官鬼、我克者妻财。
- **六神**：按日干起，甲乙起青龙，丙丁起朱雀，戊起勾陈，己起腾蛇，庚辛起白虎，壬癸起玄武，自初爻而上。
- **动变**：动爻阴阳互易得变卦，变爻六亲仍以本卦宫五行为准。
- **伏神**：本卦六亲不全时，取本宫首卦同位之爻为伏神，压于飞神之下。
- **断法**：先按所问取用神（问财取妻财、问工作取官鬼、问文书取父母、问子女取子孙、问同辈取兄弟），再看用神旺衰、旬空、动爻生克、世应关系。用神两现时取动者、临世者或旺者。

## 三种起课方式

| 方式 | 说明 | 适用 |
|---|---|---|
| **时间起课** | 自动取当下农历月、日、时辰，大安起正月顺数 | 事发即占，最常用 |
| **报数起课** | 心中默事，随口报 1–3 个数 | 无明确时间，或需以数应事 |
| **随机起课** | 凝神默念后直接起课，取三随机数 | 临时起意 |

「另择时刻」里既可填公历时刻自动倒推农历，也可直接改农历月/日/时辰三项——后者等同于以数起课，适合推算已发生之事。

## 演算规则

六宫顺行不逆，至空亡复归大安：

```
大安 → 留连 → 速喜 → 赤口 → 小吉 → 空亡 →（回大安）
 1      2      3      4      5      6
```

- **三步起课**：大安起正月，顺数至当月 = 第一落宫；该宫起初一，顺数至当日 = 第二落宫；该宫起子时，顺数至当下时辰 = 第三落宫。
- **三宫含义**：天时（起因）· 地利（过程）· 人和（结果）。
- **报数**：一数落天时，二数落地利，三数落人和；只报一数直断，报两数首尾并参。
- **断法**：以末宫定成败，以首宫观起因。首尾皆吉则事顺；始吉终凶宜见好即收；首凶终吉则先难后易。

数学上等价于：`主宫序号 = (月 + 日 + 时 − 3) mod 6`（0 即大安）。此式已在 `tools/test-engine.js` 中以全部 4320 组月日时交叉验证。

## 梅花易数规则

八卦先天数：乾一、兑二、离三、震四、巽五、坎六、艮七、坤八。

- **时间起卦**：上卦＝(年支序＋月＋日)÷8 取余；下卦＝(年支序＋月＋日＋时)÷8 取余；动爻＝(年支序＋月＋日＋时)÷6 取余。余 0 取满数。
- **数字起卦**：一数÷8 为上卦，二数÷8 为下卦，两数之和÷6 为动爻。
- **体用**：动爻所在之卦为「用」，另一卦为「体」。体主己身，用主所占之事。
- **生克**：用生体、体用比和为吉；体克用吉而费力；体生用为耗；用克体为凶。
- **互卦**：取本卦二三四爻为下、三四五爻为上，观事之中程。
- **变卦**：动爻阴阳互易，观事之终局。

`tools/test-meihua.js` 校验了 64 卦表完整性（8×8 全覆盖、无重复）、八卦爻象、体用判定 4096 组、时间起卦 51840 组。

## 奇门遁甲规则

采 **时家奇门 · 转盘 · 拆补法**。另有置闰法、飞盘法、阴盘奇门，起局与排布皆有出入，不可混用。

- **定局**：天文算法求太阳视黄经（VSOP87 简化式）定节气，以当日符头（甲/己日）地支定上中下元，查二十四节气三元局数表，得阳遁或阴遁几局。冬至后阳遁顺行，夏至后阴遁逆行。
- **地盘**：按局数布三奇六仪（戊己庚辛壬癸丁丙乙），阳遁顺九宫、阴遁逆九宫。
- **天盘**：旬首所遁之仪为值符，值符加时干落宫，其余八星依次随转。天禽寄坤二，随天芮同宫。
- **八门**：旬首原宫之门为值使，自值使起按阳顺阴逆数至时支，落宫后八门依次排布。
- **八神**：值符起于值符落宫，阳顺阴逆布：值符、腾蛇、太阴、六合、白虎、玄武、九地、九天。
- **方位**：九宫即定方位（坎北、艮东北、震东、巽东南、离南、坤西南、兑西、乾西北）。**盘成即可读方，不依赖罗盘**；罗盘只在实地方位对照时作辅助。

`tools/test-qimen.js` 校验节气时刻（对照公开历表）、干支日连续性、时干五鼠遁、局数表完整性，并对 2000 个时刻抽样验证排盘不变量（地盘九干不重、天盘八星/八门/八神各不重复、值符必在天盘、天禽随天芮、三吉门必齐）。

## 本地运行

需要一个静态服务器（`file://` 打开时 Service Worker 与「添加到主屏」不生效）：

```bash
cd daoshu
python -m http.server 8791
```

然后在本机访问 `http://127.0.0.1:8791`。

**让 iPhone 访问**（同一 Wi-Fi 下）：

```bash
python -m http.server 8791 --bind 0.0.0.0
```

查本机局域网 IP（Windows）：

```powershell
Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notlike '127.*' }
```

iPhone 的 Safari 里打开 `http://<电脑IP>:8791` 即可。注意：非 https 的局域网地址在 iOS 上**不能**添加到主屏（Safari 会隐藏该选项），要装到主屏需走 https 域名。

## 在线更新文件（含图片）

仓库里的文件可以直接在网页上改，不需要装 Git 客户端。

**改文字、改代码（纯文本）**

1. 打开 <https://github.com/JustinDoF/Tao>
2. 点进要改的文件（如 `js/data.js`），点右上角 **铅笔图标**
3. 改完 → 页面底部 **Commit changes** → 直接提交到 `main`

**换图标（PNG 等图片）**

1. 打开 <https://github.com/JustinDoF/Tao/tree/main/icons>
2. 点右上角 **Add file → Upload files**
3. 把 PNG 拖进虚线框，**文件名必须与原来一致**（如 `icon-180.png`），GitHub 会自动覆盖同名文件
4. 页面底部 **Commit changes**

> 注意：`icon-180.png` 是 iPhone 主屏图标，改完要在手机上**删掉主屏图标重新添加**才会生效（iOS 缓存图标很顽固）。尺寸必须是 180×180。

**换整套图标**：本地改 `tools/gen-icons.js` 里的配色或比例，跑 `node daoshu/tools/gen-icons.js` 重新生成，再按上面步骤覆盖上传。
